# Hole in One for Godot

This project is a proof-of-concept for rhythm-based mechanics in Godot--featuring
a RhythmEngine class that I created that acts as a signal bus for rhythm-related
stuff like a metronome and song events. I'll add a better explanation to my dedicated RhythmEngine repo
whenever I make that.
